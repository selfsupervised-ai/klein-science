1. `conformance/oracles/run_programs.py` (line 1 `# provenance: original`; stdlib only).
   - CLI: `--input <jsonl>` (repeatable; the cases are the union), `--out <dir>`, `--jobs N` (default 4), `--cpu-seconds S` (default 60), `--mem-bytes B` (default 2147483648), `--prelude <module>` (optional), `--require-sympy-env` (flag).
   - Input lines are `{"case_id": <sha256 hex of the UTF-8 code>, "code": <str>}`. Verify that each case_id equals the sha256 of its code, and exit 2 on a mismatch.
   - Each case runs in a fresh `subprocess.Popen([sys.executable, "-s", "-c", WRAPPER], stdin=DEVNULL, ...)` with an explicit env:
     - PYTHONHASHSEED and PATH;
     - PYTHONDONTWRITEBYTECODE=1;
     - SYMPY_GROUND_TYPES, MPMATH_NOGMPY, SYMPY_USE_CACHE, LC_ALL and TZ copied from the parent;
     - PYTHONPATH only when set by xtask.
   - A `preexec_fn` sets RLIMIT_CPU to S (soft) and S+1 (hard), RLIMIT_AS to B and RLIMIT_FSIZE to 64 MiB. The wall-clock kill is at 4×S.
   - WRAPPER:
     - optionally imports the prelude module and calls its `install()`;
     - compiles the program with filename "<program>" and execs it as `__main__`;
     - on an exception, writes one JSON line `{"type": type(e).__name__, "message": str(e)}` to fd 3, a dedicated pipe. SystemExit with code 0 or None counts as success.
   - Capture stdout up to 1 MiB, decoded as UTF-8 with errors="backslashreplace", and set `stdout_truncated` when it hits the cap.
   - Status rules:
     - SIGXCPU, or a kill at the wall clock, gives "timeout";
     - an exception record gives "error";
     - otherwise "ok".
   - Write `/out/records.jsonl` with one JSON object per case: keys case_id, status, stdout, stdout_truncated, exception (object or null). Sort the records by case_id. Never drop a case.
   - Write `/out/run.json` with: python version, platform.machine(), the PYTHONHASHSEED value, the env pins, jobs, limits, counts by status, and (when sympy is importable) sympy.__version__, mpmath.__version__, the effective ground types and the mpmath backend.
   - With `--require-sympy-env`, exit 3 before running any case unless the ground types report "python" and mpmath's backend reports "python". Read them from `sympy.external.gmpy` and `mpmath.libmp.backend.BACKEND`; confirm the attribute names in the installed sources.

| Boundary | Description |
|----------|-------------|

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

Repository inputs are mounted read-only and only a fresh temp dir is writable. Every flag is asserted by grep in the acceptance criteria. |
