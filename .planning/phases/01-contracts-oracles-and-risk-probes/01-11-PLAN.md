Complete the probe (ACCEL-01; CONF-06 baselines).

1. `kernels.rs` adds:
   - `mulhi_u32_limb16`: u32 mulhi from 16-bit limbs using only 32-bit operations;
   - `mul_u64_wrapping`: u64 `wrapping_mul`;
   - `mont_mul_u32`: Montgomery multiply mod p = 2013265921 with R = 2^32, using the precomputed `-p^-1 mod 2^32`;
   - `fma_probe_f32`: computes `a*b + c` with a = 1 + 2^-12, b = 1 - 2^-12 and c = -1, plus a lane of other inputs whose fused and unfused results differ;
   - `reassoc_probe_f32`: `(a + b) + c` against `a + (b + c)` with cancelling magnitudes.
2. `main.rs`:
   - Each integer kernel is checked bit-exact against its CPU reference (u64 as `wrapping_mul`, Montgomery against a u128 CPU implementation) before timing.
   - The fast-math probes report, per path, `fma_contraction: fused|unfused` and `reassociation: observed|not-observed`, by comparing f32 bit patterns with CPU unfused IEEE results and with `f32::mul_add`.
   - CPU baselines: `mont_mul_u32` over the same inputs on 1 thread and on 10 threads (std::thread::scope, equal contiguous chunks). Each thread first calls `pthread_set_qos_class_self_np(QOS_CLASS_USER_INTERACTIVE, 0)` through a local `extern "C"` declaration. Report the median and spread over 30 runs and record that macOS cannot hard-pin P-cores (assumption A9).
   - Watchdog harness:
     - `--watchdog [--max-loops N]` re-invokes the probe binary as `--watchdog-trial <loops>` in fresh subprocesses with a 120 s wall timeout each. A trial dispatches a Montgomery loop of `<loops>` iterations per element.
     - Start at 2^10 loops and double until a trial fails (non-zero exit, a device-lost or timeout message, or the wall timeout). Then binary-search between the last pass and the first fail until the gap is within 5%.
     - Report: limit_loops; the measured kernel duration at the limit (ms); the passing and failing trials bracketing it; the failure-mode text.
     - `--max-loops` caps the search for a safe self-test.
3. `bench.rs`:
   - `probe metal` without `--watchdog` runs both feature paths, all kernels and the CPU baselines.
   - `--watchdog` adds the watchdog search on the wgpu-msl path. `--full` runs everything.
   - Merge the outputs into one canonical report with sections per path, plus `cpu_baselines` and `watchdog`.
4. Run `cargo xtask bench probe metal --box mac-m3max` (no watchdog) and commit the report. Then run the harness self-test, `cargo xtask bench probe metal --box mac-m3max --watchdog --max-loops 65536`, which is expected to finish with no failure and to report `limit_loops: null` and `reached_cap: true`. Record it in the SUMMARY as the plumbing check. The real search is Task 3, with the operator present.
