1. `crates/ksci-wire/src/frame.rs`, re-exported as `ksci_wire::frame`:
   - `read_request_frame(&mut impl Read) -> Result<Option<Vec<u8>>, FrameError>`:
     - `Ok(None)` on clean EOF before a length prefix.
     - `FrameError::TooLarge(len)` when the big-endian u32 length exceeds `MAX_DOCUMENT_BYTES`, checked before allocating.
     - `FrameError::Truncated` when EOF arrives mid-frame.
   - `write_response_frame(&mut impl Write, tag: u8, payload: &[u8])` writes a u8 tag, a big-endian u32 length and the payload.
   - Tags: `TAG_OK = 0`, `TAG_BAD_REQUEST = 1`, `TAG_UNSUPPORTED_OP = 2`, `TAG_INTERNAL = 3`.
   - Add `pub mod frame;` to lib.rs.
2. `crates/ksci-ops`:
   - Package `ksci-ops` with `[lints] workspace = true`; deps ksci-wire (path) and thiserror (workspace).
   - `pub enum OpError { BadRequest(String), UnsupportedOp(String), Internal(String) }`.
   - `pub struct StepBudget`:
     - `StepBudget::new(steps: u64)`;
     - `charge(&mut self) -> core::ops::ControlFlow<()>` decrements and breaks when no steps remain.
   - The registry is `const OPS: &[(&str, fn(&Request, &mut StepBudget) -> Result<Response, OpError>)]`. Its only entry is `("science.cas.canonicalize", canonicalize)`.
   - `pub fn invoke(request_jcs: &[u8]) -> Result<Vec<u8>, OpError>`:
     - `Request::from_canonical_slice`; any WireError becomes BadRequest with the error text;
     - look up the op; an unknown op is UnsupportedOp(op name);
     - `StepBudget::new(budget.steps_u64())`;
     - run the op and return `Response::to_jcs()`.
   - `canonicalize` requires args to have exactly the key "expr", otherwise BadRequest.
     - It runs `table.canonicalize_with(&mut || budget.charge())`.
     - Some(t) gives `Response { v: 1, status: Exact, numeric_class: "exact", result: Some(t), identity: Some(sha256_hex(&t.to_jcs())) }`.
     - None gives `Response { v: 1, status: FuelExhausted, numeric_class: "exact", result: None, identity: None }`.
3. `crates/ksci-worker`:
   - Package `ksci-worker` (bin) with `[lints] workspace = true`; deps ksci-wire and ksci-ops.
   - main loop: read a request frame; on Some(bytes), call `ksci_ops::invoke`; write `TAG_OK` with the response, or the matching error tag with the UTF-8 message; flush.
   - On `None`, exit 0. On TooLarge, write a `TAG_BAD_REQUEST` frame naming the limit and exit with code 2. On Truncated, exit with code 2.
   - No env reads, no clocks, no threads.
4. Prove the path: in `crates/ksci-ops/src/lib.rs` add a unit test `ops_canonicalize_tracer`. It builds the canonical request bytes for x**2 + 1 with its nodes listed out of canonical order and steps "100", calls invoke, and asserts:
   - status exact;
   - the result equals `Table::canonicalize` of the input;
   - identity equals `Table::identity`.

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-10 | Denial of service | frame reader | high | mitigate | The length prefix is checked against MAX_DOCUMENT_BYTES before allocating. An oversized frame gets a bad-request frame and exit 2. Truncated frames give exit 2. Canonicalise is iterative and charged by StepBudget. |
| T-01-11 | Tampering | request digest uniqueness | high | mitigate | ksci_ops::invoke accepts only Request::from_canonical_slice input, so one request has exactly one byte form and one digest. |
| T-01-12 | Denial of service | panics on malformed input | medium | mitigate | Every decode error maps to an OpError and an error frame. The tests cover malformed, non-canonical, unsupported and oversized input. panic=abort only ever turns a residual bug into a host-visible process error, never into a result. |
| T-01-SC | Tampering | cargo dependencies | low | mitigate | No new external crates. ksci-ops and ksci-worker depend only on ksci-wire and the already-pinned thiserror. Cargo.lock changes only by adding the two workspace crates. |
