Build the Python wire path end to end (DET-01, GUEST-02, D-01). Every .py file starts with `# provenance: original`.

Monty-subset shape for files under standin/sympy: no class statements, no decorators, no generators, no match, no del. Imports are limited to `json`, plus `hashlib` in tests only.

1. `standin/sympy/__init__.py`: the header plus a module docstring naming this as the klein-science SymPy stand-in. Plan 01-12 generates the full name table into this file.
2. `standin/sympy/_wire.py`:
   - `dumps(value) -> bytes`, implementing RFC 8785 for the value domain None, bool, int, str, list and dict with str keys:
     - keys sorted by `k.encode("utf-16-be")`;
     - string escapes exactly `\"`, `\\`, `\b`, `\f`, `\n`, `\r`, `\t`, and other code points below 0x20 as `\u00xx` in lowercase hex; everything else is emitted raw as UTF-8;
     - ints in decimal; bool as true or false; None as null;
     - a float raises TypeError; a str containing U+D800..U+DFFF raises ValueError.
   - `canonicalize(table: dict) -> dict` mirrors ksci-wire exactly:
     - iterative post-order DFS from root with an explicit list stack;
     - children in the order given;
     - each node keyed by `dumps` of the node with canonical child indices, and deduplicated through a dict from key bytes to new index;
     - emit at first completion, drop unreachable nodes, root last;
     - return `{"nodes": [...], "root": n, "v": 1}`.
3. `standin/sympy/_tool.py`:
   - module global `_transport = None`;
   - `call(op, args, steps)` builds `{"args": args, "budget": {"steps": str(steps)}, "op": op, "v": 1}`, encodes it with `_wire.dumps`, and calls `_transport(request_bytes)`, which returns `(tag, payload_bytes)`;
   - tag 0 returns `json.loads(payload)`. Tags 1, 2 and 3 raise RuntimeError with the text "klein tool error <tag-name>: <message>". A missing transport raises RuntimeError("no klein tool transport installed").
4. `standin/host_shim/__init__.py` (CPython-only; it may use subprocess, struct and os):
   - `install(worker_path=None)` sets `sympy._tool._transport`. The worker path comes from the argument or `KSCI_WORKER`, must be absolute, and must be an existing file; otherwise raise ValueError.
   - With no path and no `KSCI_WORKER`, it installs a transport that raises RuntimeError("no klein tool transport: set KSCI_WORKER"). This is the default inside oracle containers.
   - The transport starts one `subprocess.Popen([path], stdin=PIPE, stdout=PIPE)` lazily (no shell). It writes the u32 big-endian length and the request, reads the u8 tag, u32 length and payload, and increments the module counter `calls`.
   - Provide `reset()` to stop the child and zero the counter.
5. `standin/tests/__init__.py` (header) and `standin/tests/test_wire.py` (unittest):
   - add `standin/` to sys.path first and assert `sympy.__file__` lies under standin/;
   - `test_dumps_roundtrip_corpus`: for each line L of `testdata/wire/requests.jsonl`, `_wire.dumps(json.loads(L)) == L`;
   - `test_worker_differential`: install host_shim with `KSCI_WORKER`, defaulting to `<repo>/target/release/ksci-worker`. For each corpus request whose response is exact, `_tool.call(op, args, steps)` returns a response whose `result` equals `_wire.canonicalize(args["expr"])` and whose `identity` equals `hashlib.sha256(_wire.dumps(result)).hexdigest()`. For the steps "1" request, the response has status fuel_exhausted;
   - `test_rejects_float_and_surrogate`;
   - `test_no_call_on_import`: after `import sympy`, `host_shim.calls == 0`.
   - When the worker binary is missing, fail with "run: cargo build -p ksci-worker --release". Never skip.
6. Run `cargo build -p ksci-worker --release --locked`, then the test.
